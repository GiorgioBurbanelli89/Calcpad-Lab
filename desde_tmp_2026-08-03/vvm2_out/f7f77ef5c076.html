Cyclic Damage - Concrete under Cyclic Loading (Scalar Damage, Hysteresis)

The same scalar damaged-elasticity concrete of the Concrete Damage example is driven

through a cyclic strain protocol (load reversals with growing amplitude). The damage is a

persistent state = the historical maximum, so it only grows; unloading and reloading

ride the degraded secant to the origin:

σ = (1 − d)·E·ε,  d = max historical damage of the active branch.

Two state variables are kept: ε_tmax (largest tensile strain seen) and ε_cmax (largest

compressive magnitude seen). They never reset, so each reversal recovers stiffness (crack closure) but

the secant flattens every cycle. This reproduces the secant (no plastic offset) response of

ASDConcrete1D (ASDEA/STKO). Sign convention: tension ε > 0, compression ε < 0.

Material properties (same as Concrete Damage)

Elastic modulus - E = 30000

Compressive strength (MPa) - fc = 30

Compressive peak strain - εc0 = 0.002

Compressive ultimate strain - εcu = 0.0035

Tensile strength (MPa) - ft = 3

Tensile cracking strain - εt0 = ftE = 330000 = 0.0001

Tensile softening characteristic strain - εtf = 0.0005

Compressive softening slope (residual 0.2·f_c at ε_cu) - Z = 1 − 0.2εcu − εc0 = 1 − 0.20.0035 − 0.002 = 533.333333

Numerical guard around ε = 0 - εtol = 10-6

Damaged-elasticity update rule

ε_tmax ← max(ε_tmax, ε), ε_cmax ← max(ε_cmax, −ε)

σ = (1 − d_t(ε_tmax))·E·ε if ε ≥ 0, σ = (1 − d_c(ε_cmax))·E·ε if ε < 0.

The max updates are self-selecting: a compressive step (ε < 0) cannot raise ε_tmax and a

tensile step cannot raise ε_cmax, so the active branch simply freezes the other one.

Validation table (envelope peaks)

The cyclic response must touch the monotonic envelope at each reversal peak. Peak strains:

⃗εpk = [-0.0006; -0.0012; -0.002; -0.003; -0.004; 0.0001] = [-0.0006 -0.0012 -0.002 -0.003 -0.004 0.0001]

Peak strain vector ε - ⃗εpk = [-0.0006 -0.0012 -0.002 -0.003 -0.004 0.0001]

Peak stress vector σ (MPa) - ⃗σpk = [-15.3 -25.2 -30 -14 -6 3]

Peak damage vector d - ⃗dpk = [0.15 0.3 0.5 0.8444444 0.95 0]

Key peaks: ε = −0.0006 → σ = −15.30, d = 0.150; ε = −0.0020 → σ = −30.00, d = 0.500 (f_c);

ε = −0.0030 → σ = −14.00, d = 0.844; ε = −0.0040 → σ = −6.00, d = 0.950; ε = +0.0001 → σ = 3.00, d = 0.

Cyclic strain protocol

Reversals with growing amplitude (compression cycles with unload-to-zero plus one tension excursion):

0 → −0.0006 → 0 → −0.0012 → 0 → −0.0020 → 0 → −0.0030 → 0 → +0.0001 → 0 → −0.0040

Way-points of the protocol - ⃗w = [0; -0.0006; 0; -0.0012; 0; -0.002; 0; -0.003; 0; 0.0001; 0; -0.004] = [0 -0.0006 0 -0.0012 0 -0.002 0 -0.003 0 0.0001 0 -0.004]

The protocol is discretised into n_sub = 40 sub-steps per segment, N = 441 strain points.
