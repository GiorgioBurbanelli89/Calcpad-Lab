Quadratic Equation

f ( x )  = a · x2 + b · x + c = 0

Coefficients:

a = 2  , b = 3  , c = -5 

Discriminant:

D = b2 − 4 · a · c = 32 − 4 · 2 ·  ( -5 )  = 49

The discriminant is grater or equal to zero. Real roots exist.

q = -0.5 ·  ( b + sign ( b ≡ 0 + b )  ·    √ D )  = -0.5 ·  ( 3 + sign ( 3 ≡ 0 + 3 )  ·    √ 49 )  = -5

x1 = qa = -52 = -2.5 , x2 = cq = -5-5 = 1
