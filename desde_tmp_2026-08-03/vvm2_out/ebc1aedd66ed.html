Cubic Equation

f ( x )  = x3 + a · x2 + b · x + c = 0

Coefficients:

a = -6  , b = 11  , c = -6 

Solution:

Q = a2 − 3 · b9 =  ( -6 ) 2 − 3 · 119 = 0.3333333

R = 2 · a3 − 9 · a · b + 27 · c54 = 2 ·  ( -6 ) 3 − 9 ·  ( -6 )  · 11 + 27 ·  ( -6 ) 54 = 0

Check: R2 = 02 = 0 < Q3 = 0.33333333 = 0.03703704

There are three real roots.

θ = acos(R   √ Q3) = acos(0   √ 0.33333333) = 1.570796

x1 = -2 ·    √ Q · cos(θ3) − a3 = -2 ·    √ 0.3333333 · cos(1.5707963) − -63 = 1

x2 = -2 ·    √ Q · cos(θ − 2 · π3) − a3 = -2 ·    √ 0.3333333 · cos(1.570796 − 2 · 3.1415933) − -63 = 2

x3 = -2 ·    √ Q · cos(θ + 2 · π3) − a3 = -2 ·    √ 0.3333333 · cos(1.570796 + 2 · 3.1415933) − -63 = 3
