Concrete Damage - Scalar Damaged Elasticity (CDP-type)

Uniaxial damaged-elasticity model for concrete (scalar damage, Concrete Damaged Plasticity style):

σ(ε) = (1 − d(ε))·E·ε,  with scalar damage d ∈ [0, 1] growing during softening.

Sign convention: tension is ε > 0 (positive), compression is ε < 0 (negative).

Material properties

Elastic modulus - E = 30000

Compressive strength (MPa) - fc = 30

Compressive peak strain - εc0 = 0.002

Compressive ultimate strain - εcu = 0.0035

Tensile strength (MPa) - ft = 3

Tensile cracking strain - εt0 = ftE = 330000 = 0.0001

Tensile softening characteristic strain - εtf = 0.0005

Compressive softening slope (residual 0.2·f_c at ε_cu) - Z = 1 − 0.2εcu − εc0 = 1 − 0.20.0035 − 0.002 = 533.333333

Numerical guard around ε = 0 - εtol = 10-6

Constitutive law σ(ε) (stress in MPa)

Tension (ε ≥ 0):  σ = E·ε if ε ≤ ε_t0 (elastic), else σ = f_t·exp(−(ε−ε_t0)/ε_tf) (exponential softening) Compression (ε < 0, x = −ε): σ = −f_c·(2·(x/ε_c0) − (x/ε_c0)²) if x ≤ ε_c0 (Kent-Park/Hognestad parabola),

else σ = −f_c·max(0.2, 1 − Z·(x − ε_c0)) (linear softening down to residual 0.2·f_c)

Scalar damage variable

d(ε) = clamp( 1 − σ(ε)/(E·ε), 0, 1 ),  d = 0 at ε = 0.

Validation table (reference strains)

Reference strains swept with a loop to evaluate the model:

⃗εref = [-0.0035; -0.003; -0.002; -0.001; 0.0001; 0.0003; 0.001] = [-0.0035 -0.003 -0.002 -0.001 0.0001 0.0003 0.001]

Strain vector - ⃗εref = [-0.0035 -0.003 -0.002 -0.001 0.0001 0.0003 0.001]

Stress vector σ (MPa) - ⃗σref = [-6 -14 -30 -22.5 3 2.01096 0.4958967]

Key points: peak compression at ε = −0.002 gives σ = −30 MPa, d = 0.50; peak tension at ε = +0.0001 gives σ = 3 MPa, d = 0.
