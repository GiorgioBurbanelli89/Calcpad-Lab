8. Cálculo e interpolación

integral integral2 integral3 trapz fzero polyfit interp1 ode45
Ejemplo — integral y raíz: 
I = integral(@(x) exp(-x.^2), 0, 1)
r = fzero(@(x) cos(x) - x, 0.5)
Ejemplo — integral matricial (FEM Bᵀ·D·B): 
B = [1 0 0.5; 0 1 0.5];
D = [2 0.5; 0.5 2];
t = 0.3;
Ke = integral(@(eta) integral(@(xi) (B'*D*B*t), ...
     -1,1,'ArrayValued',true), -1,1,'ArrayValued',true)

13. Constructor de loop (∑ ∏ ∫)

Escribe loop en el editor (o menú Insert → ∑ ∏ ∫): eliges operador, expresión y límites, y la forma (bucle for o función). La integral ofrece integral, trapz, trapecio, Simpson, y doble/triple.

Ejemplo — sumatoria (bucle vs función): 
s = 0;
for k = 1:10
    s = s + (k^2);
end
s

s2 = sum(arrayfun(@(k) (k^2), 1:10))
