M∫C Hekatan Lab

Hojas de cálculo científicas con sintaxis MATLAB. Basado en el motor de Calcpad (Ganchovski).

Cómo funciona

  1. Escribe tus fórmulas y código MATLAB en el panel Code (izquierda).
  2. Pulsa F5 o el botón ▶ para calcular. El resultado sale en Output (derecha).
  3. Exporta el reporte a HTML, PDF o Word con los iconos de la esquina superior derecha. (El PDF y Word siempre salen en hoja blanca.)

Sintaxis MATLAB

  • Asignación: a = 42, v = [1 2 3], M = [1 2; 3 4]
  • Rangos: x = 0:0.1:10  ·  linspace(a, b, n)
  • Elemento a elemento: .* ./ .^  ·  transpuesta A'
  • Control: for, while, if / elseif / else, function
  • Handles: @(x) x.^2  ·  arrayfun, integral, fzero, ode45
  • Simbólico: syms x, diff, int, solve, jacobian, simplify

Empieza a escribir y aparece una lista de autocompletado con las funciones. Escribe . para ver los operadores punto (.*, ./, .^, .').

Constructor de loop (∑ ∏ ∫)

Para escribir sumatorias, productorias e integrales en notación matemática y convertirlas a MATLAB:

  • Escribe la palabra loop en el editor, o menú Insert → ∑ ∏ ∫ Constructor de loop.
  • Elige el operador, escribe la expresión y los límites, y elige la forma: por bucle for (ves cada iteración) o por función compacta.
  • La integral ofrece varias formas: integral(), trapz, trapecio y Simpson por bucle; y doble (integral2) y triple (integral3).

Ejemplo — sumatoria por bucle:

s = 0;
for k = 1:10
    s = s + (k^2);
end

También reconoce la notación compacta al escribirla: a = $Area{x^2 @ x = 0 : 1} se reescribe sola a a = integral(@(x) (x^2), 0, 1, 'ArrayValued', true) — MATLAB portable, seguro con matrices (FEM Bᵀ·D·B).
