+ 13. Constructor de loop (∑ ∏ ∫)

Escribe loop en el editor (o menú Insert → ∑ ∏ ∫): eliges operador, expresión y límites, y la forma (bucle for o función). La integral ofrece integral, trapz, trapecio, Simpson, y doble/triple.

Extras de Hekatan Lab (dentro de % — renderizan en el output):
%' texto/título visible %% sección (oculto) % #noc fórmula % #md … #endmd % #plain % #render %{ … %} oculto

La notación Calcpad $Plot, $Sum, $Area… no se usa en Hekatan Lab: al escribirla se transforma a MATLAB (plot, sum(arrayfun(…)), integral). Grafica siempre con plot/surf.

Ejemplo — reporte con texto, fórmula y gráfica (MATLAB): 
%' Viga simplemente apoyada
%' Momento máximo:
% #noc M_max = q*L^2/8
q = 5; L = 6;
M = q*L^2/8
x = linspace(0, L, 100);
plot(x, q*x.*(L-x)/2)
xlabel('x [m]'); ylabel('M [kN·m]'); grid on
